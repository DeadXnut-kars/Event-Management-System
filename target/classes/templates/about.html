System Architecture & Design

About EventHub

A lightweight web platform for publishing events, preventing registration duplicates, and managing attendee capacities.

The Problem We Solved

Organizing community meetups, technical hackathons, and conferences using scattered forms and chat channels usually breaks down fast:

Duplicate Registrations Attendees submit multiple responses when unsure if their submission went through, skewing headcount figures.
Accidental Overbooking Static forms have no concept of physical room limits, causing venues to overcrowd.
Communication Loss Event dates, links, and venue directions get buried under hundreds of messages in group chats.
Door Check-In Chaos Checking names on mobile spreadsheets at the entrance creates long queues and verification delays.

Core Engine Features

Duplicate Prevention

Enforces email uniqueness per event at both the application service layer and database schema level (via a composite unique constraint), rejecting repeat signups.

Live Capacity Tracking

Every event validates remaining seats in real time against its defined capacity before writing new registrations, automatically marking events "Sold Out" once full.

Digital Pass Issuance

Generates a unique alphanumeric reference code (e.g. EVT-2026-X89J) and formats a printable, verifiable pass for every confirmed attendee.

Organizer Console

Centralized dashboard allowing organizers to create events, edit details, track attendance metrics, search attendees, and cancel registrations.

Technical Stack & Architecture

EventHub is built using a clean, decoupled MVC architecture with server-side template rendering:

Component Technology Role in System
Backend Framework Spring Boot 3 (Java 21) Embedded Tomcat container, dependency injection, and REST/MVC request routing.
Persistence Layer Spring Data JPA & Hibernate Object-relational mapping, transaction boundaries, and automated repository query execution.
Database MySQL 8 / InnoDB (or in-memory H2) ACID-compliant relational storage with foreign key cascades and unique constraints.
View Layer Thymeleaf & Bootstrap 5 Server-side HTML5 template rendering with responsive CSS layouts and form validation feedback.

Database Design

Table Key Attributes Integrity Rules
events id, title, category, event_date, venue, capacity, organizer_name, organizer_email, status Primary entity. Stores event metadata and max capacity threshold.
registrations id, registration_code, event_id, participant_name, email, phone, organization, role_title FOREIGN KEY (event_id) REFERENCES events(id) ON DELETE CASCADE
UNIQUE (event_id, email) prevents duplicate submissions.
